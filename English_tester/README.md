# VocabDrill - Cognitive Lexical Testing & Error Analysis System

**VocabDrill** — це сучасна науково орієнтована настільна платформа на Python (`customtkinter`) для тестування англійсько-українського та українсько-англійського словникового запасу з **посимвольним аналізом помилок (Character-Level Alignment Diff)**, **прогресивними підказками**, **гранулярним вибором конкретних слів з кожного блоку** та надійною обробкою рядка вводу.

---

## 🌟 Основні Можливості та Оновлення

### 1. Науковий, Чіткий та Структурований Інтерфейс
* **Лабораторна колірна палітра**: Висококонтрастна темна тема (Academic Slate & Cyan `#38bdf8`) з вивіреною типографікою та чіткими межами блоків.
* **Наукова телеметрія (HUD)**:
  - Відображення ідентифікатора блоку (`БЛОК ID`), номера спроби та індексу картки (`Картка: k / N`).
  - Статистичні показники у реальному часі: точність \(P_{\text{acc}}\), кількість правильних відповідей (\(N_c\)), помилок (\(N_e\)) та пропущених карток (\(N_s\)).
* **Граматичні мітки (POS Tags)**: Автоматичне виявлення та відображення частин мови (`[NOUN]`, `[VERB]`, `[ADJECTIVE]`, `[VERBAL PHRASE]`).
* **Аналітичний диф-аналіз**: Розрахунок коефіцієнта схожості за метрикою Левенштейна (`Similarity Index: XX.X%`) та посимвольне підсвічування розбіжностей без передчасного розкриття синонімів чи альтернативних відповідей.

### 2. Режим Речень із Контекстним Використанням Слів (Sentence Cloze Mode)
* **Два режими тестування**:
  - `Слова (Words)`: Класичний режим тренування окремих слів та фраз.
  - `Речення (Sentences)`: Режим контекстного використання слів у реченнях (Cloze Deletion Test).
* **Автоматична та кураторська генерація речень**:
  - Для лексики передбачено великий корпус живих контекстних речень (як загальних, так і технічних: IT, бази даних, системний аналіз).
  - Динамічний генератор з урахуванням частин мови (дієслова, іменники, прикметники, прислівники) для будь-яких додаткових слів.
* **Інтелектуальне маскування слів (Stem & Inflection Matching)**:
  - Враховує відмінки та закінчення українських та англійських слів (наприклад, `фактичний` -> `[ _______ ] вартість`).
  - Відображає речення з пропуском `[ _______ ]` та підказку/контекст вихідною мовою.
  - Після правильної відповіді або відкриття підказки пропуск заповнюється повним словом із підсвічуванням (`✓ [ слово ]`).

### 3. Гранулярний Вибір Слів з Кожного Блоку
* **Акордеон для кожного розділу/блоку**: Можливість натиснути `▼ Слова (N)`, щоб розгорнути повний перелік лексичних одиниць даного блоку.
* **Індивідуальні чекбокси**: Дозволяють обирати або виключати конкретні слова всередині будь-якого розділу.
* **Швидке керування блоком**: Кнопки `Всі` та `0` для миттєвого вибору або зняття всіх слів окремого розділу.
* **Глобальні інструменти**: Кнопки `Обрати всі слова` та `Зняти всі`, лічильник загальної кількості обраних слів (`Обрано: X / Y слів`).
* **Фільтрація у реальному часі**: Пошуковий рядок миттєво фільтрує розділи та слова як за англійським текстом, так і за українським перекладом.

### 3. Звіт Сесії, Аналіз Помилок та Їх Повторення
* **Детальний підсумковий список слів**:
  - `❌ Слова з помилками`: виділяються червоним із зазначенням кількості спроб та останнього введеного варіанта.
  - `✓ Правильно засвоєні слова`: відображаються зеленим із позначкою про проходження з першої спроби.
  - `⏭ Пропущені слова`: перелік слів, які було пропущено.
* **Посилене повторення проблемних слів**:
  - `🔁 Повторити все (помилки × 3)`: перезапускає сесію, в якій кожне слово з помилкою з'являється **по 3 рази** у випадковому порядку.
  - `🎯 Тільки проблемні слова (× 3)`: фокусний режим тренування виключно тих слів, де були допущені помилки (також по 3 повтори для надійного закріплення).
* **Приховано передчасні підказки**: під час перевірки та підказок приховано список альтернативних прийнятих слів, щоб не підказувати відповідь завчасно.

### 4. Виправлення Помилок з Рядком Вводу та Підказками
* **Усунено зависання тексту ("skip" / залишковий ввід)**:
  - Завдяки безпечній ініціалізації `_reset_entry()` стан поля завжди нормалізується перед викликом очищення або вставки, що усуває баг Tkinter, коли очищення заблокованого поля (`disabled`) ігнорувалося.
  - При переході до наступної картки рядок гарантовано очищується та активується.
* **Політерна кнопка `💡 Підказка` (Progressive Letter-by-Letter Hint)**:
  - При першому натисканні відкривається **лише перша буква** слова, а всі інші залишаються замаскованими (`_`).
  - При кожному наступному натисканні відкривається наступна літера (2-га, 3-тя і так далі).
  - Очищує будь-який хибний ввід та залишає поле вводу активним і сфокусованим з курсором у кінці.
* **Кнопка `👁 Розкрити`**:
  - Показує повний еталонний переклад у полі вводу та диф-панелі, перемикаючи кнопку на `Наступна картка ➔ (Enter)`.
* **Кнопка `⏭ Пропустити` та ввід "skip"**:
  - Якщо користувач натискає кнопку або вводить слово `"skip"` чи `"скіп"` безпосередньо в рядок, система виконує чистий пропуск без залишкового сміття у полі.
